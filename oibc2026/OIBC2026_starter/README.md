# 2026 POSTECH OIBC Big Data Challenge X 제6회 POSTECH-UNIST-KAIST AI & 데이터사이언스 경진대회
## 데이터 안내 — 태양광 집합자원 구성·예측

태양광 발전소 253개소(합계 42,655.4 kW)를 두 집합자원 G1, G2에 배정하고, 각 집합의 시간별 발전량을 하루 전에 예측합니다. 배정과 예측을 어떤 순서로, 어떤 단위로 다룰지는 열려 있습니다.

## 과제에서 정하는 것

1. **구성** — `sites.csv`의 253개소를 G1 또는 G2 중 하나에 배정합니다. 평가 기간 동안 하나의 배정을 유지합니다. 각 집합의 설비용량 합계는 20,000 kW 이상입니다.
2. **예측** — 집합별·시각별 발전량(kWh)을 제출합니다. 예측시점은 대상일 전일 17:00 KST입니다. 제출 시각은 `smp.csv`의 8,760행(2025-06-01 01:00 ~ 2026-06-01 00:00 KST)과 같습니다.

정산은 그 시각의 전력가격(SMP)과 시간대 가중치 `k`를 사용합니다. `k`는 `ts`의 시가 11~15이면 3, 그 외는 1입니다. 식과 동점 처리, 제출 횟수는 문제정의서에 있습니다.

```
S = Σ SMP(t)·실적(t)  −  0.10 × Σ SMP(t)·k(t)·|예측(t) − 실적(t)|
```

## 제출하는 파일

참가자가 만드는 파일입니다. 열 이름·행 수·무효 조건의 정본은 문제정의서입니다.

```csv
site_id,group
PV001,G1
PV002,G2
```

`composition.csv`는 헤더 포함 254행입니다. `site_id`는 `sites.csv`의 253개 전부입니다.

```csv
group,ts,forecast_kwh
G1,2025-06-01 01:00:00+09:00,0.0
G2,2026-06-01 00:00:00+09:00,0.0
```

`forecast.csv`는 헤더 포함 17,521행입니다. G1·G2 각각 `smp.csv`의 8,760시각이고, `ts`에는 타임존이 있어야 합니다. `forecast_kwh`는 0 이상입니다.

## 컬럼

### `sites.csv`

| 컬럼 | 뜻 |
|---|---|
| `site_id` | 익명 ID (`PV001`~`PV253`) |
| `current_group` | 참조 배정 `A` 또는 `B`. 제출 배정과는 별개이며, 바꿔도 됩니다 |
| `capacity_kw` | 설비용량 (kW). 253개소 합계 42,655.4 |
| `lat`, `lon` | 위경도 (WGS84). 비식별을 위해 이동·반올림된 좌표 |
| `wa_station`, `wb_station` | 기상 제공사 A·B 관측지점 ID |
| `wa_dist`, `wb_dist` | 발전소에서 그 지점까지의 직선거리 (m, 100 m 단위) |

A 지점은 61개(`WA001`~), B 지점은 73개(`WB001`~)입니다. 여러 발전소가 같은 지점을 가리킵니다. 거리 중앙값은 A 약 6.9 km, B 약 5.0 km이고, 최댓값은 A 약 15.5 km, B 약 13.0 km입니다.

좌표는 발전소마다 최대 2 km 안에서 이동한 뒤 소수 4자리로 반올림한 값입니다. 이동량은 발전소별로 고정되어 있습니다. `wa_station`, `wb_station`, `wa_dist`, `wb_dist`는 이동 전 위치 기준이라, 제공된 `lat`·`lon`으로 거리를 다시 재면 파일의 거리와 달라집니다. 좌표로 발전소·사업자·원래 위치를 특정하는 행위는 문제정의서의 실격 사유입니다.
